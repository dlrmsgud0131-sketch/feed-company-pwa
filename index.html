💾 데이터 백업 / 복원

모든 원료·배합비·재고 데이터를 파일로 저장하고 복원합니다
📥 백업 (내보내기)
현재 모든 데이터를 하나의 파일로 저장합니다. 정기적으로 백업해 두면 브라우저 문제로 데이터가 사라져도 복원할 수 있습니다.
📤 복원 (불러오기)
백업 파일의 데이터를 온라인(Supabase)에 병합 복원합니다. 같은 기록은 중복되지 않으며, 모든 PC에 반영됩니다.
🐄 한우 데이터 백업
사육·출하·폐사 현황을 하나의 파일로 저장합니다(내보내기 전용 — 복원은 관리자에게 문의하세요).
☁️ 자동 일일 백업
로그인 시 하루 1회, 서버 전체(배합·원료·재고·한우)를 자동으로 스냅샷합니다(최근 7일 보관). 아래에서 날짜를 눌러 파일로 내려받을 수 있습니다.
확인 중...
💡 안전 팁: 모든 데이터(배합이력·원료·재고·사육/출하/폐사)는 온라인(Supabase)에 저장됩니다. 백업은 만일의 서버 문제에 대비한 스냅샷입니다. 월 1회 정도 백업을 권장합니다.

⚙️ 출하처 온라인 조회 — 설정 ✕
여기서 바꾼 내용은 이 브라우저(PC)에만 저장됩니다. 실제 조회가 되는 출하처(협신식품·홍주미트)는 이름/안내문만 수정 가능하고 삭제할 수 없습니다(연동 파서가 코드에 있어야 하므로). 새 출하처는 "준비중" 항목으로 추가해두면 나중에 연동 작업의 참고 목록이 됩니다.
🏪 출하처 관리
👤 위탁자 설정 (사업자번호/주민번호 프리셋)

☁️ 출하처 온라인 조회 ✕
출하처 사이트에서 출하내역을 조회해 출하현황에 병합합니다. 사육현황에 같은 이력번호가 있으면 정액·유전능력 등을 자동으로 채우고, 출하완료 처리 여부를 물어봅니다.
🔍 데이터 확인 ✕
🏠 위탁자→목장명 매핑 ✕
출하처 온라인 조회 결과에서 사육현황에 이력번호가 없는(신규) 개체는 목장명을 알 수 없는 경우가 많습니다. 위탁자(출하자) 이름과 실제 목장명을 매핑해두면 그 이름으로 출하된 소는 자동으로 이 목장명이 붙습니다. (사육현황에 이미 등록된 이력번호가 있으면 그 목장명이 항상 우선합니다.)
